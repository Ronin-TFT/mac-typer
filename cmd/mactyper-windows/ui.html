输入内容

可直接拖入文本文件
手误：英文字母按概率误按相邻键（有时多打一个字母才发现），随后删除并改正。

每行写：原词=>错词，例如 mother=>motter；# 开头为注释

快捷键（后台也可用）

至少包含 Ctrl、Alt 或 Win；录制时按 Esc 取消，执行期间不能录制。

说明

按键使用系统 SendInput 发送，不需要额外权限。如果目标程序以管理员身份运行，Mac Typer 也需要以管理员身份运行才能输入。 倒计时结束后会等你松开 Ctrl/Alt/Shift/Win 再开始输入。
