# Mac Typer

macOS 图形化模拟键入工具。核心使用 Go，界面使用原生 AppKit。

## 功能

- 基础输入间隔和随机抖动，支持 `ms` / `秒` 切换
- 导入错词库，随机删除整个错词或仅删除错误部分后重输
- 错词删除同样应用间隔和随机抖动
- 全局开始、暂停/继续、结束快捷键，可在设置中录制
- 快捷键启动延迟、辅助功能权限检测和内置教程
- 暂停发生在错词删除中途时，继续后从原位置完成删除

## 安装

下载 [`dist/MacTyper.dmg`](dist/MacTyper.dmg)，打开后把 **Mac Typer** 拖入“应用程序”。首次运行在：

`系统设置 -> 隐私与安全性 -> 辅助功能`

只为 **Mac Typer** 打开权限，不需要为终端重复授权。

默认快捷键：

- 开始：`⌥⌘B`
- 暂停/继续：`⌥⌘N`
- 结束：`⌥⌘M`

## 错词库

程序读取的格式为 `错词=>正确词`：

```txt
teh=>the
adress=>address
```

图形界面的“错词库工具”也接受 `正确词=>错词`，保存时会自动转换。

## 构建与测试

需要 macOS 13+、Go 和 Xcode Command Line Tools。

```sh
go test ./...
./build_dmg.sh
```

输出文件：`dist/MacTyper.dmg`
